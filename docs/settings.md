# Settings

The plugin has no devices, so all its settings are in one place: **Plugins → Tariff Analyser → Configure**.

## Energy data and reports

| Setting | What it does |
|---|---|
| **Timeseries DB path** | Where to find SigenEnergyManager's energy database. Leave it blank and the plugin finds it in SigenEnergyManager's own folder, which is right for almost everyone. |
| **Output folder** | Where the reports are saved. Leave it blank to use `/Library/Application Support/Perceptive Automation/TariffAnalyser/`. The plugin never deletes old reports, so you can clear the folder out whenever you like. |
| **Open report in the browser when generated by a schedule/action** | Ticked, a report made by the **Generate Tariff Comparison Report** action opens in your browser by itself. It is unticked to start with. Reports from the Plugins menu always open. |

## Tariffs

| Setting | What it does |
|---|---|
| **Octopus region (for Agile prices)** | Your area, as a letter, which decides the Agile prices used, and the Tracker price if you set a Tracker product code below. It starts at F, North East England, which is mine. The table below lists the letters. |
| **Export tariff to use in comparisons** | The export price used for every tariff in the comparison, and for the Energy Summary. It starts at **Octopus Outgoing 12p flat (actual)**. The [tariffs page](tariffs.md) lists the choices. |
| **Gas unit rate (pence/kWh)** | The price you pay for a unit of gas, used only to cost your gas in the nightly collection. It starts at 6.09. Change it when your gas price changes. |
| **Default report date range** | How many days of Agile prices the **Update Octopus Agile Price Data** action fetches, counting back from today — 30, 60, 90, 180 or 365. It starts at 30. It does not change the period of either report, which you choose each time. |

### Choosing your region

The menu gives each letter with its area:

| Letter | Area |
|---|---|
| A | Eastern England |
| B | East Midlands |
| C | London |
| D | Merseyside and North Wales |
| E | West Midlands |
| F | North East England |
| G | North West England |
| H | Southern England |
| J | South East England |
| K | South Wales |
| L | South West England |
| M | Yorkshire |
| N | South Scotland |
| P | North Scotland |

If you are on an Octopus tariff, the letter is also the last letter of your tariff's code in your Octopus account.

## Nightly collection

Both of these are optional, and only change the nightly collection. The two reports do not use them.

| Setting | What it does |
|---|---|
| **Solar install date** | The first full day your solar panels ran, written as year-month-day, such as 2026-03-13. Days before it are not counted as solar savings. Leave it blank and every day with solar data counts, which is right if SigenEnergyManager went in with the panels. |
| **Octopus Tracker product code** | If you are on Octopus Tracker, the product code of your Tracker tariff, such as SILVER-25-04-11. The plugin then fetches Octopus's published Tracker price for each day in your region. Leave it blank and the collection uses the prices SigenEnergyManager recorded, which is right for any other tariff. You can also paste the full tariff code from your Octopus account, and the plugin keeps the product part. |

The Configure box will not save a date or a code it cannot read, and says which one is wrong.

## Octopus details

These are only needed for the nightly collection of your meter readings. The two reports work without any of them.

| Setting | What it is |
|---|---|
| **Octopus API key** | A private key that lets the plugin read your meter readings from Octopus. You will find it on the API access page of your Octopus online account. Without it, there is no nightly collection. |
| **Import MPAN** | The number of the meter point you buy electricity through — the long number marked MPAN on your electricity bill. |
| **Import meter serial** | The serial number of that electricity meter, also on your bill. |
| **Export MPAN** | The MPAN of your export meter point, if you sell electricity. It is a different number from the import one. |
| **Export meter serial** | The serial number of the meter that measures your export. |
| **Gas MPRN** | The number of your gas meter point, marked MPRN on your gas bill. |
| **Gas meter serial** | The serial number of your gas meter. |

Leave out any you do not have. Without the export details the nightly collection uses SigenEnergyManager's own export figures, and without the gas details it skips gas.

### Keeping your Octopus details in one file

If you run several of my plugins, you can keep these details in one shared file instead of typing them into each plugin. The file is called `IndigoSecrets.py` and lives in `/Library/Application Support/Perceptive Automation/`. A blank copy, `IndigoSecrets_example.py`, comes inside the plugin — copy it to that folder, rename it `IndigoSecrets.py`, and fill in these lines with your own details:

| Line in the file | Setting it replaces |
|---|---|
| `OCTOPUS_API_KEY` | Octopus API key |
| `OCTOPUS_MPAN` | Import MPAN |
| `OCTOPUS_SERIAL` | Import meter serial |
| `OCTOPUS_EXPORT_MPAN` | Export MPAN |
| `OCTOPUS_EXPORT_SERIAL` | Export meter serial |
| `OCTOPUS_GAS_MPRN` | Gas MPRN |
| `OCTOPUS_GAS_SERIAL` | Gas meter serial |

When the file has a value, it is used, whatever the Configure box says. Any line the file does not have, or leaves blank as `""`, comes from the Configure box instead. The plugin reads the file when it starts, so restart it after changing the file.

Keep a copy of the file somewhere safe, such as a password manager, because it holds your private details.
