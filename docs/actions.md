# Actions

The plugin adds four actions, so you can run its work from a schedule, a trigger or an action group. Add an action and pick one of these from Tariff Analyser's actions.

The plugin adds no devices and no triggers of its own.

## Generate Tariff Comparison Report

Makes the Tariff Comparison for the **Date range** you choose — the last 7, 14, 30, 60, 90, 180 or 365 days, ending yesterday. It starts at 30 days.

The report is saved in the output folder and its ranking written to the Event Log. It only opens in the browser if **Open report in LibreOffice when generated by a schedule/action** is ticked in the plugin's settings — despite the name, it opens in your browser.

This action uses the Agile prices the plugin already has and does not fetch new ones, so put **Update Octopus Agile Price Data** before it in the same schedule or action group. Without that, Agile may show as **insufficient price data to rank**.

## Update Octopus Agile Price Data

Fetches any Agile prices the plugin does not already have, for the number of days set in **Default report date range** in the plugin's settings, counting back from today. It needs no Octopus account. The Event Log says how many prices it added.

## Update Daily Energy Summary

Runs the nightly collection straight away, for the **Days to refresh** you choose — yesterday only, or the last 3, 7, 14 or 30 days. It starts at 7 days. [How it works](how-it-works.md) explains what it collects. It needs an Octopus API key.

The plugin already does this for the last seven days at 2am each night, so you only need the action to go back further, or to fill in a gap after the Mac was off.

## Generate Energy Summary

Makes the Energy Summary and opens it in the browser on the Mac that runs Indigo, the same as the menu item.

## A morning report

To have a comparison ready each morning, create a schedule that runs at, say, 7am, and give it two actions in this order:

1. **Update Octopus Agile Price Data**
2. **Generate Tariff Comparison Report**, with the date range you want

The report then waits in the output folder, or opens by itself if you have ticked the setting above.
